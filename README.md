Live at **[rbndchsn.github.io/resume](https://rbndchsn.github.io/resume/)**, with a downloadable PDF version linked from the page.

## What this is

The online resume of Robin Duchesneau: 25 years across environmental standards authorship, certification and audit practice, sustainability consulting, and AI-enabled software for regulated domains.

## How it was built

The same way the resume says systems should be built: spec-first, with [Claude Code](https://claude.com/claude-code) doing the implementation and a human making every design decision and final call.

- A single static HTML file, no frameworks and no build step, served by GitHub Pages
- Design iterated conversationally: layout, palette, motion, and content were each specified, reviewed in the browser, and refined before committing
- Light and dark themes with a manual toggle (light is the default; the choice persists per visitor)
- Scroll-triggered reveals, count-up stats, an experience timeline, and cursor-tracking hover effects, all disabled for visitors who prefer reduced motion
- A print stylesheet so Ctrl+P produces a clean paper document
- No LLM runs at page runtime; the page is plain HTML, CSS, and a small amount of vanilla JavaScript
